「ユニフォームを新しくしたいけど、何から始めればいいかわからない」「大会に間に合うのか不安」。チームの担当になった方から、よくこんな相談をいただきます。

この記事では、INBLAZEでオーダーユニフォームを作るときの流れを、問い合わせから納品まで順番にまとめました。最後に、大会日から逆算していつまでに動き始めればいいかも紹介します。

注文の流れは5ステップ

INBLAZEのオーダーユニフォームは、次の5つのステップで進みます。

  1. お問い合わせ・お見積もり:種類と枚数を決める
  2. ヒアリング・デザイン提案:チームの色やコンセプトを聞いて、デザインの方向性を決める
  3. 修正:3回まで無料で直せる
  4. デザイン完成・入金
  5. 納品:入金確認後、約4〜5週間でお届け

大事なのは、製作が始まるのは入金を確認してからという点です。デザインが決まっていても、入金が遅れるとその分だけ届く日も後ろにずれます。

ステップ1：見積もりで決めておくこと

最初に決めておくとスムーズなのは、次の3つです。

  • アイテム:上下セットか、シャツだけ・パンツだけか
  • 枚数:選手の人数に、予備を足すかどうか
  • 使う日:最初に着る大会や試合の日

2026年11月時点の価格は次のとおりです(税込・1枚あたり)。

枚数 上下セット シャツのみ パンツのみ
1〜30枚 8,800円 6,600円 5,500円
31枚〜 ご相談 ご相談 ご相談

1着から作れて、30枚までは枚数が少なくても同じ価格です。合計3万円以上で送料は無料になります。

見積もりページでは、枚数と使う日を入れると、金額と入金期限の目安がその場でわかります。入力した内容はそのままLINEで送れます。

ステップ2〜3：デザインは「イメージ」を伝えれば大丈夫

デザインデータがなくても問題ありません。チームカラーや入れたいロゴ、「去年のユニフォームに近い感じで」といったイメージを伝えていただければ、そこから提案します。

修正は3回まで無料です。色や番号のフォント、名前を入れるかどうかなど、納得できるまで調整してから確定します。

公式戦で使う場合は、番号の大きさや色に大会の規定があることがあります。出場する大会がわかっていれば、デザインの段階で一緒に確認します。

サイズが不安なときは

「普段のサイズで大丈夫か不安」という場合は、注文前にサイズ確認用のサンプルをお貸ししています。人数が多いチームほど、先に試着しておくと安心です。

ステップ4〜5：入金から届くまで約4〜5週間

デザインが決まって入金を確認したら、製作に入ります。届くまでの目安は入金確認後、約4〜5週間です。数量や時期によって前後することがあるので、日程が決まっている場合は早めに伝えてください。

大会に間に合わせるための逆算

例えば、3月20日の大会で新しいユニフォームを着たい場合を考えてみます。

  • 入金の目安:大会の約5週間前 → 2月13日ごろまで
  • デザインの相談:修正のやり取りを考えると、入金の目安よりさらに前から

つまり、大会のおよそ2か月前には相談を始めておくと安心です。

見積もりページで使う日を入れると、この入金期限の目安が自動で表示されます。間に合うか微妙なときも、まずは一度ご相談ください。

まとめ

  • 流れは「見積もり → デザイン提案 → 修正 → 入金 → 納品」の5ステップ
  • 製作は入金確認後に始まり、届くまで約4〜5週間
  • 大会日から逆算して、2か月前を目安に相談を始める

ユニフォームは、チームの気持ちがそろうきっかけにもなります。「とりあえず金額だけ知りたい」という段階でも大丈夫なので、気軽に見積もりを試してみてください。
